# 用户习惯与要求记录（进化日志）

> 本文件是 skill 的"记忆"：每次任务后把用户新增/修改的翻译习惯、排版要求、摘要要求记录在此；
> 反复出现、已稳定的要求上提到 SKILL.md 对应小节。新装此 skill 时本文件应为空模板，随使用逐渐填充。

## 记录格式

```
## YYYY-MM-DD 事件名
1. 要求内容（尽量可执行、可检验）
2. …
```

## 示例（删除此节后开始记录）

- 双栏对照排版：左栏英文原文不变，右栏中文译文与原文排版一致
- 术语与缩写：译后以括号保留原文，如「监督学习（supervised learning）」
- 图形不译：图片、曲线图保持原位置与原排版
- 结构化摘要：背景目的 / 核心判据及机制 / 方法 / 关键参数与结论 / 适用条件与局限
